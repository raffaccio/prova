Obiettivi del Tutorial

Un header serve a identificare la parte superiore di un sito, spesso contenente il logo e il menu di navigazione.

<header class="main-header">
    <h1>Titolo del sito</h1>
    <p>Sottotitolo o descrizione</p>
</header>

    • 2. Personalizzazione con CSS

    Con CSS possiamo migliorare l'aspetto dell'header, ad esempio modificando colori, font e margini.

    .main-header {
    background-color: #0073e6;
    color: white;
    text-align: center;
    padding: 20px;
}
